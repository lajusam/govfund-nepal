# Place your background music file here

## music.mp3 Placement

Due to copyright, a music track is not included. Place a calm, ambient instrumental
track at this path:

  remotion-video/public/music.mp3

Recommended:
- YT Audio Library: "A New Beginning" or "Calming" category
- Free Music Archive: search "ambient governance"
- Pixabay: https://pixabay.com/music/ (search "corporate ambient")

Once placed, set `AUDIO_ENABLED = true` in src/Video.tsx.
